# CityClinic Feedback Bot

Telegram-бот для сбора обратной связи от пациентов клиники «СитиКлиник».

## Что делает бот

1. Принимает данные пациента в формате:

```text
Иван Иванович, +79991234567
```

2. Перед отправкой сценария проверяет телефон пациента в базе `reviewed_patients`. Если телефон уже есть в базе, бот не отправляет пациенту сообщение, потому что этот пациент уже оставлял отзыв.

3. Если телефона еще нет в базе, просит пациента оценить визит от 1 до 5.

4. Если оценка 5:
   - просит написать или продиктовать отзыв;
   - распознает голос, если пациент отправил голосовое сообщение;
   - показывает пациенту текст отзыва;
   - дает ссылку на Яндекс.Карты;
   - пишет инструкцию: «Пожалуйста, выберите 5*, вставьте отзыв и нажмите "Опубликовать"».

5. Если оценка ниже 5:
   - просит написать или продиктовать замечания;
   - не ведет пациента на сторонние ресурсы;
   - отправляет переписку в Telegram-группу клиники.

6. После получения текстового или голосового отзыва бот заносит телефон пациента в базу уже оставивших отзыв.

7. Вся переписка отправляется в отдельную Telegram-группу.

## Как запустить локально

### 1. Установите Python

Рекомендуется Python 3.11.

Проверьте версию:

```bash
python --version
```

### 2. Создайте виртуальное окружение

```bash
python -m venv .venv
```

Активируйте его на Windows:

```bash
.venv\Scripts\activate
```

На macOS / Linux:

```bash
source .venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Создайте файл `.env`

Скопируйте `.env.example` в `.env`:

```bash
copy .env.example .env
```

На macOS / Linux:

```bash
cp .env.example .env
```

Заполните значения:

```env
BOT_TOKEN=токен_бота_из_BotFather
ADMIN_GROUP_ID=-1001234567890
CLINIC_NAME=СитиКлиник
YANDEX_MAPS_REVIEW_URL=https://yandex.ru/maps/213/moscow/?ll=37.524386%2C55.631916&mode=poi&poi%5Bpoint%5D=37.524289%2C55.631968&poi%5Buri%5D=ymapsbm1%3A%2F%2Forg%3Foid%3D105460760425&z=21
OPENAI_API_KEY=ключ_OpenAI_если_нужно_распознавание_голоса
```

Если `OPENAI_API_KEY` не указан, текстовые отзывы будут работать, но голосовые сообщения не будут распознаваться.

### 5. Добавьте бота в Telegram-группу клиники

1. Создайте группу в Telegram.
2. Добавьте туда бота.
3. Дайте боту право отправлять сообщения.
4. Узнайте ID группы.

Самый простой способ узнать `ADMIN_GROUP_ID`:

- временно добавьте в группу бота `@RawDataBot` или аналогичный сервисный бот;
- он покажет ID группы;
- ID супергруппы обычно выглядит так: `-1001234567890`.

### 6. Запустите бота

```bash
python bot.py
```

В Telegram напишите боту:

```text
/start
```

Затем отправьте:

```text
Иван Иванович, +79991234567
```

## Деплой на Railway

### 1. Загрузите проект на GitHub

```bash
git init
git add .
git commit -m "Initial CityClinic feedback bot"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/cityclinic-feedback-bot.git
git push -u origin main
```

### 2. Создайте проект на Railway

1. Откройте Railway.
2. Нажмите **New Project**.
3. Выберите **Deploy from GitHub repo**.
4. Выберите репозиторий с ботом.

### 3. Добавьте переменные окружения

В Railway откройте раздел **Variables** и добавьте:

```env
BOT_TOKEN=...
ADMIN_GROUP_ID=...
CLINIC_NAME=СитиКлиник
YANDEX_MAPS_REVIEW_URL=...
OPENAI_API_KEY=...
```

### 4. Проверьте запуск

Railway увидит `Procfile` и запустит:

```bash
python bot.py
```

## Защита от повторного запроса отзыва

После получения отзыва бот сохраняет телефон пациента в таблицу `reviewed_patients`.

Телефон нормализуется: из номера удаляются пробелы, скобки, дефисы и другие символы. Например:

```text
+7 (999) 123-45-67 -> 79991234567
8 999 123 45 67     -> 79991234567
```

При следующем вводе пациента бот сначала проверяет эту таблицу. Если номер найден, новая сессия не создается и сообщение пациенту не отправляется.

## Важное замечание

Бот не публикует отзыв за пациента и не имитирует действия на Яндекс.Картах. Пациент самостоятельно открывает Яндекс.Карты, выбирает 5*, вставляет свой отзыв и нажимает «Опубликовать».


## Админ-команды

Эти команды нужно писать в админ-группе, где находится бот.

```text
/id
```

Показывает ID текущего чата. Именно это значение нужно указывать в Railway в переменной `ADMIN_GROUP_ID`.

```text
/reviewed
```

Показывает список телефонов пациентов, которые уже оставляли отзыв.

```text
/delete_reviewed +79991234567
```

Удаляет номер из базы уже оставивших отзыв. После удаления этому пациенту снова можно будет отправить сценарий сбора отзыва.

## Распознавание голоса

Для распознавания голоса нужна переменная окружения:

```env
OPENAI_API_KEY=ваш_ключ_OpenAI
```

Если ключ не задан или указан неверно, бот попросит отправить отзыв текстом. Ошибка будет отображаться в логах Railway в формате `Voice transcription error: ...`.
