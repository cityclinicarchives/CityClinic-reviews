# CityClinic Feedback Bot — Wazzup WhatsApp version

Проект запускается из Telegram-бота администратора, а вся переписка с пациентом идет в WhatsApp через Wazzup API.

## Как работает сценарий

1. Администратор пишет Telegram-боту `/new`.
2. Администратор отправляет данные пациента:

```text
Иван Иванович, +79991234567
```

3. Бот проверяет базу `reviewed_patients`.
4. Если пациент уже оставлял отзыв, новое сообщение не отправляется.
5. Если пациент еще не оставлял отзыв, бот отправляет ему сообщение в WhatsApp через Wazzup.
6. Пациент отвечает оценкой `1`, `2`, `3`, `4` или `5`.
7. При оценке `5` бот сразу отправляет пациенту просьбу оставить отзыв на Яндекс.Картах и завершает сценарий. Текст отзыва в WhatsApp больше не запрашивается.
8. Ссылка на Яндекс.Карты отправляется через промежуточный URL сервиса `/yandex/{session_id}`: при клике бот фиксирует переход и отправляет уведомление в Telegram-группу, затем перенаправляет пациента на Яндекс.Карты.
9. При оценке ниже `5` бот просит замечания и не ведет пациента на Яндекс.Карты.
10. Ответ пациента при оценке ниже `5` уходит в Telegram-группу клиники.
10. Если для голосового сообщения включалось распознавание ИИ, в отчете указывается примерный расход токенов. Если ИИ не включался, указывается 0.

## Переменные Railway

В Railway → Variables нужно добавить:

```env
BOT_TOKEN=токен_телеграм_бота
ADMIN_GROUP_ID=-1001234567890
CLINIC_NAME=СитиКлиник
YANDEX_MAPS_REVIEW_URL=https://yandex.ru/maps/...
OPENAI_API_KEY=ключ_OpenAI_если_нужно_распознавание_голоса
PUBLIC_BASE_URL=https://your-app.up.railway.app
WAZZUP_API_TOKEN=токен_Wazzup_API
WAZZUP_CHANNEL_ID=uuid_канала_Wazzup
```

`PUBLIC_BASE_URL` — это домен Railway без `/` в конце.

## Команды администратора

```text
/start
```
Показать помощь.

```text
/new
```
Начать отправку пациенту в WhatsApp.

```text
/id
```
Показать ID текущего Telegram-чата.

```text
/reviewed
```
Показать номера пациентов, уже оставивших отзыв.

```text
/delete_reviewed +79991234567
```
Удалить номер из базы уже оставивших отзыв.

```text
/wazzup_channels
```
Показать каналы Wazzup и их `channelId`.

```text
/setup_wazzup_webhook
```
Подключить webhook Wazzup на адрес:

```text
https://your-app.up.railway.app/wazzup/webhook
```

```text
/wazzup_webhook
```
Показать текущую настройку webhook Wazzup.

```text
/health
```
Проверить, что Telegram-часть сервиса отвечает.

## Первый запуск на Railway

1. Загрузите файлы проекта в GitHub.
2. Создайте Railway-проект из GitHub.
3. В Railway → Networking сгенерируйте домен. Если просит порт, укажите `8000`.
4. Добавьте переменную:

```env
PUBLIC_BASE_URL=https://ваш-домен.up.railway.app
```

5. Добавьте остальные переменные из раздела выше.
6. Сделайте Redeploy.
7. В Telegram напишите боту:

```text
/wazzup_channels
```

8. Скопируйте `channelId` активного WhatsApp-канала и добавьте в Railway:

```env
WAZZUP_CHANNEL_ID=скопированный_channelId
```

9. Сделайте Redeploy.
10. В Telegram напишите:

```text
/setup_wazzup_webhook
```

11. Проверьте:

```text
/wazzup_webhook
```

## Проверка полного цикла

1. В Telegram:

```text
/new
```

2. Затем:

```text
Тест Иванович, +79000000000
```

3. На WhatsApp должен прийти запрос оценки.
4. Ответьте в WhatsApp:

```text
5
```

5. Бот должен сразу отправить сообщение со ссылкой на Яндекс.Карты.
6. Нажмите ссылку — в Telegram-группу должно прийти уведомление о переходе.
7. При оценке ниже `5` отправьте замечание текстом или голосом.
8. В Telegram-группу администраторов должна прийти вся переписка.

## Важно про WhatsApp и Wazzup

Для обычного WhatsApp-канала Wazzup использует `chatId` как телефон пациента только цифрами, например `79011112233`. Для отправки через API используется `POST /v3/message`.

Для WABA могут действовать ограничения 24-часового окна и шаблонов. Если у вас подключен WABA, первое сообщение может потребовать согласованный шаблон.
